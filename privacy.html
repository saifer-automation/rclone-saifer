Политика конфиденциальности

rclone Saifer. Действует с 17.10.2026.

Кто пользуется

Приложение используется только его владелицей для работы с её собственным Google Диском. Другим людям оно не предлагается.

К каким данным есть доступ

К файлам Google Диска владелицы в пределах разрешения, которое она выдала сама. Приложение загружает на Диск и читает только те файлы, которые владелица выбрала для копирования.

Где хранятся данные

Разрешение на доступ хранится только на компьютере владелицы, в настройках программы rclone. Серверов у приложения нет, никуда кроме Google Диска владелицы данные не отправляются.

Передача третьим лицам

Данные никому не передаются и не продаются, не используются для рекламы и для обучения моделей. Использование данных, полученных через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ

В любой момент на странице разрешений аккаунта Google.

Изменения

При изменении политика обновляется на этой странице с новой датой.
